# 衡动工作室 (Kinetix Studio) — 智能渐进健身助理

打造一款专注于科学力量训练与长期进步追踪的个人健身助理网站。系统能够智能解析您以往的训练计划，结合近期实际完成的负重与次数自动生成每日渐进超负荷计划，提供流畅的组间记录体验与多维度可视化进步图表。

- **已确认 — 每日计划生成逻辑**：由 AI 结合您最近数次同动作的历史实际完成数据（重量、次数、完成率），依据渐进超负荷原则（Progressive Overload）自动推荐当日目标重量与组数，并附带简明的调整理由。

- **预设默认项 — 初始体验与单位制**：默认以公制千克（`kg`）记录负重（支持随时切换 `kg / lbs`），并内置一套可随时一键清空或替换的真实多周训练样本数据，方便首次打开即可直观体验历史对比与长期趋势图表。

## 1. 产品概览与核心理念

- **核心功能定位**：将“旧计划迁移 → 每日智能排课 → 训中逐组记录 → 长期数据复盘”串联为闭环工作台。不仅解决“今天练什么、该加多少重量”的决策负担，更让每一次重量与容量的突破清晰可见。
- **目标场景与人群**：适合有一定训练基础、希望系统执行分化训练（如推拉腿、上下肢、五分化等）并持续追踪力量与训练容量增长的健身者，兼顾桌面端复盘规划与移动端训中单手快捷打卡。
- **核心价值**：
  - **零门槛迁移旧计划**：无需逐个字段繁琐填表，粘贴自由文本即可生成可编辑的周期模板。
  - **有据可依的每日进阶**：每组输入框旁直观展示“上次同动作表现”与“今日推荐目标”，告别凭感觉盲目加减重。
  - **直观量化长期进步**：自动换算估算极限重量（Estimated 1RM）与单次总容量（Tonnage），用清晰图表呈现真实训练趋势。

## 2. 用户体验与视觉设计

### 核心用户流程

1. **导入或配置计划模板**：进入“计划模板”视图，粘贴以往的训练计划文本点击“AI 智能解析”，预览并确认识别出的训练日分化（如推日、拉日、腿日）及各动作基准组数与次数区间；也可随时手动编辑或选用内置经典分化模板。
2. **生成今日训练计划**：在“今日训练”工作台选择今日目标分化（或按周期顺序自动匹配），点击“AI 生成今日计划”。系统读取历史日志，自动填入今日每个动作的建议重量、目标次数与组数，并展示单行教练提示（例如：“上次 80kg 4×8 全部达标，今日建议微增至 82.5kg”）。
3. **训中逐组打卡与计时**：训练过程中，逐组核对或微调实际完成的重量（提供 `±2.5kg` 快捷步进器）与次数，点击完成勾选框即自动触发顶部非遮挡式组间休息倒计时（默认 90 秒，可自定义增减或跳过）。支持临时新增动作、增删热身组/正式组及填写训练备注。
4. **完成结算与纪录突破**：点击“完成今日训练”后，系统汇总本次总容量、总组数、训练时长，自动检测并高亮标记打破个人最佳纪录（PR，含最大负重与最高估算 1RM）的动作，归档至本地历史日志。
5. **复盘长期趋势图表**：切换至“趋势分析”面板，按时间跨度（近 4 周 / 12 周 / 全部）与具体动作查看力量增长曲线、周训练容量柱状图及各肌群训练组数均衡度。

### 视觉识别与主题规范（现代中性工作室风）

- **美学基调**：克制、专业、通透的建筑感工作室美学。摒弃花哨霓虹渐变与多层嵌套阴影卡片，依靠精准留白、1px 细腻分割线与高辨识度数字排版传递秩序感。
- **60-30-10 色彩系统**：
  - **60% 主背景画布 (`--background`)**：柔和暖石浅灰 `#F6F6F4`，降低长时间浏览的视觉刺眼感。
  - **30% 结构表面与边框 (`--surface` / `--border`)**：纯白单层卡片 `#FFFFFF` 搭配 `#E5E5E0` 细边框；主文本采用深炭黑 `#181816`，次要说明采用中性灰 `#6B6B66`（严格满足 WCAG AA 对比度）。
  - **10% 语义与行动强调色 (`--primary` / `--accent`)**：主行动按钮采用沉稳炭黑 `#181816`；组数完成与力量正向进阶采用森林翠绿 `#15803D`（搭配明确文字或对勾图标，绝不仅凭颜色传达状态）；平台期或减载提示采用琥珀色 `#D97706`；删除等危险操作采用深绯红 `#DC2626`。
- **2+1 字体层级与等宽数字纪律**：
  - **标题与品牌展示**：`Plus Jakarta Sans` 搭配中文无衬线字体，字重利落，标题统一约束折行平衡。
  - **正文与辅助说明**：`DM Sans` 搭配中文无衬线字体，行高舒展易读。
  - **数据与计时器专用等宽字体**：所有负重数值、次数、组数、容量汇总、日期与倒计时均强制启用 `JetBrains Mono` 与等宽数字对齐（`tabular-nums`），确保列表上下小数点与数位严丝合缝、数值跳动时版面零抖动。
- **组件与空间排版纪律**：
  - **三区顶栏契约**：桌面端顶部导航严格保持单行三区结构——左侧纯文字品牌标识、中部 4 个单行视图导航链接（`今日训练`、`计划模板`、`历史日志`、`趋势分析`）、右侧单一主行动按钮（`AI 生成今日计划`）；移动端底部提供符合拇指热区的固定四栏标签导航（固定元素总高度严格控制在视口高度 15% 以内），所有交互点击区域不小于 `44×44px`。
  - **零胶囊静态标签**：动作所属肌群、器械类型、预计时长与日期等静态元数据均采用清爽的无框文本加 `·` 分隔符展示（如 `胸部 · 杠铃 · 目标 4 组`），不堆砌彩色胶囊徽章；仅可点击筛选的分段控制器使用干净的按钮态样式。
  - **单层卡片深度**：全站保持单一卡片层级，卡片内部通过留白与极细横线划分动作与组次行，绝不出现“卡片套卡片”或粗左侧色条。
- **微交互与反馈状态**：按钮与打卡勾选响应控制在 `150ms` 内；AI 解析与生成期间展示结构对齐的骨架屏加载态；新用户清空数据后提供引导清晰的空状态操作入口；打卡完成与数据备份操作通过轻量化顶部通知条反馈。

## 3. 核心产品决策与权衡

- **决策 1：AI 智能推荐结合本地确定性兜底**
  - *采用方案*：通过服务端安全调用 Gemini 模型进行自然语言计划解析与渐进超负荷推演，同时在前端内置基于 Epley 公式与线性进阶规则的快速预设填充能力。
  - *原因*：既能理解千人千面的自由格式旧计划文本、给出有针对性的进阶建议，又保证即使在离线或手动微调场景下依然随时可用、零阻塞记录。
  - *舍弃方案*：纯静态固定课表（无法根据上次力竭或超额完成情况动态调重）或纯对话式聊天机器人（在健身房组间记录时打字对话效率极低，不如结构化表格直观）。
- **决策 2：浏览器本地持久化 + 双格式文件备份**
  - *采用方案*：采用浏览器本地存储实时自动保存每一次组数勾选与输入修改，并提供 JSON 全量快照导入/导出与 CSV 明细导出。
  - *原因*：契合您的选择，实现打开即用、训中意外刷新不丢进度，同时允许随时将数据备份到本地文件或在电脑与手机浏览器间迁移。
- **决策 3：多维力量指标设计（最大重量 + 估算 1RM + 训练容量）**
  - *采用方案*：在趋势图表中同时支持查看“单组最高重量”、“估算极限重量 (1RM)”与“总训练容量 (重量×次数)”。
  - *原因*：力量训练中，有时重量不变但每组多做了 2 次同样是显著进步；引入估算 1RM（$\text{重量} \times (1 + \text{次数}/30)$）与总容量曲线，能更客观全面地反映真实水平提升。

### 核心数据实体

- **训练计划方案 (WorkoutProgram)**：包含方案名称、分化周期列表（`SplitDay`，如“推日：胸肩三头”），每个分化日下包含有序动作列表（动作名称、目标肌群、器械分类、目标组数、目标次数下限与上限、基准参考重量及动作要领）。
- **单日训练计划与进行中会话 (ActiveSession)**：绑定具体日期与分化日，包含 AI 生成的整体训练提示、各动作的当日推荐重量/次数理由，以及实时编辑中的每组记录（`SetEntry`：组号、组类型[热身/正式]、重量、次数、RPE 主观疲劳度、是否已完成打卡）。
- **历史训练日志 (WorkoutLog)**：已完成归档的训练记录快照，自动计算并存储当日总容量、完成总组数、耗时及单动作最佳 1RM，作为后续 AI 排课与可视化图表的数据源。

### 关键交互与状态流转映射

- **AI 解析旧计划流转**：用户输入文本点击解析 → 按钮进入加载防抖态并请求 `/api/ai/parse-plan` → 服务端校验并按严格 JSON Schema 返回分化结构 → 前端在预览区展示解析结果供用户核对微调 → 点击“保存为当前计划”写入本地状态并自动持久落盘；若输入为空或网络异常，内联展示清晰错误提示并保留原文本。
- **今日训练打卡与草稿保护**：训中每一次修改重量、次数、增删组数或点击完成勾选框，均实时同步至本地进行中草稿（防止误关页面丢失数据）；点击勾选框同时唤醒顶部倒计时器并重算当前已完成容量进度。
- **可视化图表联动筛选**：在“趋势分析”中选择特定动作（默认自动选中训练频次最高的核心复合动作）或切换时间窗口时，客户端实时聚合历史日志序列，动态更新力量曲线、最高纪录摘要指标与空数据提示。
